# Решения проекта Question-To-Quiz

## DEC-001. Правило оценивания попытки

**Статус:** принято  
**Дата:** 29 октября 2026 года

### Контекст

После завершения или истечения времени попытки сервер должен самостоятельно
рассчитать результат пользователя.

Оценивание выполняется только по сохранённым копиям вопросов и вариантов из
таблиц `quiz_questions` и `quiz_answer_options`.

Изменения исходного банка вопросов после создания квиза не должны влиять на
результат уже созданной попытки.

### Источник правильного ответа

Правильность варианта определяется исключительно авторским полем `is_correct`
в таблице `quiz_answer_options`.

Система:

- не анализирует смысл текста;
- не исправляет авторскую разметку;
- не сравнивает ответы по тексту или буквам;
- не использует AI для определения правильного ответа.

### Правило оценивания вопроса

Для каждого вопроса применяется следующее правило:

1. Если пользователь выбрал вариант с `is_correct = true`, ответ считается
   правильным.
2. Если пользователь выбрал вариант с `is_correct = false`, ответ считается
   неправильным.
3. Если пользователь не выбрал вариант, вопрос считается пропущенным.
4. Если ни один вариант не отмечен как правильный:
   - выбранный пользователем вариант считается неправильным;
   - вопрос без выбранного варианта считается пропущенным.
5. Если правильными отмечены несколько вариантов, выбор любого варианта с
   `is_correct = true` считается правильным.

Неоцениваемых вопросов в текущей версии продукта нет.

### Итоговые показатели

Результат содержит:

- `total_questions` — общее количество вопросов;
- `answered_questions` — количество вопросов с сохранённым ответом;
- `correct_answers` — количество правильных ответов;
- `wrong_answers` — количество неправильных ответов;
- `unanswered_questions` — количество пропущенных вопросов;
- `percentage` — процент правильных ответов;
- `started_at` — время начала попытки;
- `finished_at` — время завершения или истечения попытки;
- `status` — `completed` или `expired`.

Должны выполняться равенства:

`total_questions = correct_answers + wrong_answers + unanswered_questions`

`answered_questions = correct_answers + wrong_answers`

### Формула процента

Процент рассчитывается по формуле:

`percentage = correct_answers / total_questions * 100`

Если `total_questions` равен нулю, сервер возвращает `percentage = 0` и не
выполняет деление.

### Подробный результат

Подробный результат разделяется на три массива:

- `correct` — вопросы с правильными ответами;
- `wrong` — вопросы с неправильными ответами;
- `unanswered` — вопросы без сохранённого ответа.

Для каждого вопроса возвращаются:

- идентификатор;
- текст;
- позиция;
- выбранный пользователем вариант или `null`;
- варианты ответа;
- авторская отметка `is_correct` для каждого варианта.

Правильные ответы и поле `is_correct` нельзя возвращать, пока попытка имеет
статус `in_progress`.

Они становятся доступны только после завершения попытки или истечения
дедлайна.
